# LearningSpace 页面结构与关键流程设计 V0.1

状态：V0.1 页面结构与关键流程设计已全部通过 Review；PRD V0.1 已通过 Review。  
配套原型：[静态页面原型](LearningSpace-wireframes-v0.1.html)  
需求依据：[PRD V0.1](../requirements/LearningSpace-PRD-v0.1.md)

## 1. 设计目标与边界

让家庭成员打开工作台就能看全今天的任务及预计用时汇总，并方便打印执行与集中回填。“接下来做”仅在对应任务行高亮，不占独立卡片。另展示固定安排；从老师消息整理任务后，先确认任务，再确认计划。家长与孩子使用完全相同的入口。

本轮是信息结构与交互提案。静态原型采用构造数据，用于审阅页面关系、内容顺序与关键状态，不连接识别服务、不保存业务数据，也不代表自动排程已实现。原型中的动作标注表达拟议操作，跨页链接只切换示例画面。

已确认需求继续遵守：课程表只手工录入；错题只记录；实际用时手工填写；日/周计划可打印；不做成员权限、计时器和错题复习。

## 2. 三种组织方式与推荐

| 方式 | 优点 | 代价 | 结论 |
|---|---|---|---|
| 今天为首页 | 最直接回答下一步做什么，适合打印和孩子自主执行 | 跨天调整需要进入计划页 | 推荐 |
| 周日历为首页 | 固定课程与整周负担容易对照 | 初次进入需要先找今天，易误导为逐小时排任务 | 作为计划页 |
| 全部任务为首页 | 批量整理与筛选方便 | 截止任务、重复任务、长期目标混杂，孩子需要再次选择 | 作为任务页 |

## 3. 信息结构

桌面一级导航为“今天、计划、任务、错题”；“用时统计、设置”作为低频入口。手机底部沿用四个一级入口，统计和设置通过页头更多菜单进入。不要额外引入家长/学生模式。

| 页面 | 主问题 | 主要操作 | 次级页面或面板 |
|---|---|---|---|
| 今天 | 今天有哪些任务，预计共多久？ | 打印、批量回填、完成/记录 | 任务详情、计划变更提醒 |
| 计划 | 这一周如何安排？ | 生成建议、比较变化、确认、调整单日 | 长期目标拆分、固定安排、可用时间 |
| 任务 | 有哪些要求需要整理或安排？ | 手工添加、导入消息、核对候选任务 | 任务详情、重复规则、原始资料 |
| 错题 | 题目记录在哪里？ | 拍照/上传、裁剪、分类查询、编辑 | 原图、出处与备注 |
| 用时统计 | 实际投入与估计差多少？ | 切换日/周/科目 | 缺失用时记录入口 |
| 设置 | 什么时候可以安排？ | 手工课程表、课外班、每周可用时段 | 单次调课/取消、后续规则修改 |

任务页筛选只突出“待核对、待安排、全部”，科目和标签作为可选筛选。不把任务状态全部铺成看板。

## 4. 页面设计

### 4.1 今天

优先级：日期与打印/回填 → 预计总用时及学习/锻炼汇总 → 完整今日任务清单 → 简短固定安排与待安排提醒。完成数量为辅助信息。

- 清单各行采用一致密度，显示具体内容、预计用时、科目及有关的截止提示和材料；接下来做的任务仅用浅色背景和小标识高亮，不放独立大卡片或突出操作按钮。
- 汇总同时显示预计总用时、学习与锻炼用时；各科预计用时作为紧凑分类摘要。固定课程及往返占用另列，不混入任务预计总用时。
- 未回填条目显示“未记录”而非断定“未做”。完成数量只统计已记录的完成事实。
- 标题建议显示“未记录任务预计 X 分钟”，避免把尚未回填的纸质任务误称为实际剩余工作。
- 新任务显示“有 N 项待安排，当前计划未变”，链接到建议计划，不直接插入原清单。
- 固定课外班有准确时刻；任务顺序不显示假精确的开始时间。
- 首页不展示“今天的时间”扣减明细卡片；可用时段、课程及往返扣减、休息缓冲和容量解释放在计划页。首页保留预计用时汇总，避免重复展示时间数字。
- 已记录条目仍保留在今日完整清单内，可修改记录；今日预计总用时不因完成而减少。打印入口接收当前已确认版本，建议草稿不与正式计划混用。

### 4.2 任务录入与核对

手工入口与“整理老师消息”并列。手工表单先显示任务内容、科目/标签、预计用时、截止日期；重复规则与长期拆分按需展开。

消息整理页面：桌面左侧原文/附件，右侧候选任务；手机上下排布，通过“查看原文”定位来源。

- 先录入资料并提取，再核对内容、科目、截止日期和估时。
- 将“老师明确日期”“需核对的相对日期”“系统估计用时”区别呈现。
- 缺截止日期不虚构，允许确认成无截止任务；识别不确定日期需用户核对或明确选择未设置。
- 表单保存失败保留当前输入；识别失败仍可手动整理同一份资料。
- 底部主操作是“确认并保存任务”，完成后显示“已保存，尚未安排”。“生成建议计划”是接下来的独立操作。
- 普通编辑不默认展示十余个字段；来源和附件放在任务详情内。

### 4.3 计划与变更确认

周计划采用按日分组的任务列表，固定安排在对应日期顶部。桌面可以并列多天；手机按天切换，不强制缩小七列。

生成建议后展示：

1. 各日可用时段、扣减的固定占用与保留的缓冲。
2. 建议任务和预计总量，明确学习与锻炼构成。
3. 与已确认版本相比的新增、移至其他日期、保留项。
4. 截止前排不下或超量的任务，以及待处理原因。

建议状态始终有明确标识。确认按钮说明作用范围，如“确认周四、周五的调整”；取消或离开草稿不改变已确认计划。冲突未解决时保留待安排项，不能宣称全部已安排。

原型示例：周四可用时段 17:00–21:30 共 270 分钟；英语班 19:00–20:00，加前后各 20 分钟占用共 100 分钟；家庭预留晚餐/休息 70 分钟，留给任务 100 分钟。原计划任务 95 分钟，新作业 20 分钟，合计超出 15 分钟。建议将可移动的 15 分钟阅读移至周五，周四保留 100 分钟；周五也展示调整后的余量，不能仅解决单日后把超量转移过去。

以上数字是演示数据，不是默认学习时长。时段扣减需按重叠区间计算，不将已排除的时间重复扣减。

### 4.4 长期目标、重复任务与固定安排

- 长期目标详情显示总体范围、最终截止、已完成与未来份额。数量型用页数/章节，步骤型用提纲/初稿/修改等阶段。
- 每日行只展示今天份额；点击可回到总目标。总目标不再计一次当日用时。
- 重复任务修改先问作用于“本次”还是“以后”；本次补做/跳过不重写后续。
- 固定课外班编辑提供“调整本次、取消本次、修改之后”。学校课程表只有手工维护入口。
- 可用时段允许按周设置和单日例外；休息与缓冲作为明确占用，算法不能为了塞下任务自动压缩。

### 4.5 打印

打印预览分“每日任务单、每周计划”。A4 黑白为主，不依赖科目颜色；固定安排、任务顺序、内容、预计分钟、完成框和实际分钟留白清楚可见。

- 日期、计划版本、短任务编号用于回填定位，不出现复杂内部编号。
- 原型展示周四 v1 的每日纸单；周版同样按日分组，并允许自然分页，避免为了塞进一页缩小字体。
- 计划更新后提示“纸单为 v1，当前为 v2”，可选择查看变化并重新打印。
- 不在纸单上要求扫码才能知道题目要求；必要附件可提示文件名称，第一版不制作错题练习单。

### 4.6 批量回填与未完成重排

先选择日期/纸单版本，显示原任务顺序，每行填写“未记录、已完成、部分完成、未做”。重复任务提供本次跳过处理。

- 初始没有填写的行维持未记录，不批量默认为完成或未做。
- 实际分钟可空；空不当作 0，不预填预计分钟。
- 完成可以没有实际用时，界面提示用时尚未记录，不阻止保存完成事实。
- 部分完成填写已完成量/步骤，普通任务可写剩余内容；保留当日实际分钟。
- 保存先提交执行事实，再提供“安排剩余任务”入口；用户未确认新建议前，不移到明天。
- 同一天同一条记录再次编辑是修正，不追加重复用时；跨日投入独立保存。

原型示例：数学 25 分钟、作文 18、英语阅读 15、锻炼 20、收尾 5，总计 83 分钟。按原型任务分类，学习 63 分钟、锻炼 20 分钟。作文为部分完成，剩余内容待重排；未完成母任务不抹除这 18 分钟。

### 4.7 错题与用时统计

错题页采用“图片缩略图＋科目＋出处”列表，支持搜索和编辑。录入时拍照/上传后裁剪，原图保留；不出现复习队列、下次复习、掌握度或推荐题。

统计页显示日/周范围、学习与锻炼汇总、按科目明细及未记录用时数量。预计/实际比较只对相同执行范围且有数据的记录进行；部分完成任务显示已投入，不假称省时。

## 5. 关键流程与异常

| 流程 | 主要步骤 | 关键异常处理 |
|---|---|---|
| 老师信息转任务 | 录入资料 → 提取 → 核对 → 保存任务 | 提取失败转手工；原始资料保留 |
| 任务转计划 | 选范围 → 建议 → 查看变化/冲突 → 调整 → 确认 | 截止前不足提示待安排，原计划不静默变化 |
| 新作业加入 | 新任务保存 → 显示待安排 → 重新建议 → 确认 | 已完成任务不重排，纸单版本变化可见 |
| 纸上执行 | 确认计划 → 打印 → 线下执行 → 批量回填 | 旧纸单可找到原任务，不按当前序号误配 |
| 未完成 | 保存已做部分/实际用时 → 待重排 → 建议 → 确认 | 不自动延期，不擅自改截止 |
| 单次调课 | 选择一次课程 → 改日期/时间 → 检查冲突 | 后续重复不变，学习计划变更另行确认 |

无任务、尚无计划、任务已全部完成是不同状态：无任务提示录入；未生成计划提示安排；全部完成保留已完成记录，不自动补入更多任务。

## 6. 原型阅读方式与覆盖范围

配套 HTML 为静态设计画册，含：今天首页、消息核对、计划变更、长期目标、打印样张、批量回填、错题记录、手机首页示意。页内目录可跳转，流程链接跳到对应设计画面；所有表单值与结果是演示，不发生保存。

设计覆盖 PRD 的核心链路，现已补充设置的课程表、课外班、可用时段示意，以及日/周用时统计和缺失记录示例。静态原型不包含真实编辑操作。Word/PDF 预览支持边界、部署、服务选型等仍按 PRD 第 10 节留到技术方案阶段确定。

## 7. Review 重点

1. “今天、计划、任务、错题”的主导航是否自然，统计与设置作为次级入口是否方便？
2. 首页是否能看全今日任务、预计总量与分类汇总，打印与回填是否足够明显？“接下来做”是否只需行内高亮？
3. “保存任务”和“确认计划”分两步，是否容易理解？
4. 新作业/调课造成的调整是否清楚，能否看懂哪些内容保持不变？
5. 纸单与回填的字段是否实用，是否给孩子增加不必要的记录负担？

## 9. 设置与用时统计补充设计（已确认）

### 9.1 设置页

三个分组为学校课程表、固定课外班、可用时段。低频入口从侧栏设置进入，手机保持单列按日维护。

- 学校课程表：手工录入星期、名称、起止时间；时间倒置及课程重叠给出提示，不增加识别或导入入口。
- 固定课外班：每周日期和时间，课前准备及去程合计占用、回程占用；提供调整本次、取消本次、修改之后。单次修改展示原日期、新日期及影响范围；保存约束不直接重排学习任务。
- 可用时段：每周按天设置，可添加多个不重叠区间；另设这些区间内需要保留的晚餐、休息与缓冲分钟。已在区间外排除的时间不重复扣减。
- 单日例外：选择日期覆盖当日时段或预留分钟，后续周规则保持不变。
- 容量预览：原可用区间的并集，减去与课程/往返重叠区间的并集，再减额外预留。预留超出剩余时长时提示设置冲突，不能产生负容量或自动延长时段。

原型保持周四 270−100−70＝100 分钟的示例。另给独立的周四课程调至周五示例，该调课尚未应用到其他画面，避免混淆场景。

### 9.2 用时统计页

入口独立于首页，默认按日，也可按周及科目查看。学习与锻炼分开，固定课程及往返占用不作为任务实际投入自动累计。

本轮日统计为独立缺失场景：数学实际 25、作文部分完成投入 18、英语阅读已完成但用时未填、锻炼 20、笔记整理 5。共记录 68 分钟，其中学习 48、锻炼 20；5 项中4 项填写用时，不能称为完整日总量。前文回填页则展示英语阅读已补填 15 分钟的状态，共83 分钟。

预计/实际对比限定为相同完整执行范围且用时已填的任务。本例数学、锻炼、笔记共预计50、实际50；作文部分完成只展示投入，英语用时缺失不参与快慢对比。不能直接用全部预计95减去已记录68来宣称节省27分钟。

周统计示例按日合计90＋80＋100＋68＝338，其中学习258、锻炼80，明确含周四缺失记录；未来日期显示尚未到达，历史未回填显示待回填，均不默认为0。跨日实际用时归属投入日期，长期母任务不再累计一次。

科目筛选同步作用于汇总、明细和缺失提示。没有记录时显示空状态与回填入口，不显示虚构的0分钟成绩。更正历史用时后重新汇总，不生成重复记录。

### 9.3 本轮核验与 Review 范围

检查设置分组与作用范围是否清晰，以及统计对缺失、部分完成的处理是否容易理解。原型采用静态数据，表单保存、筛选和自动扣减尚未实现；本轮只 Review 页面与规则表达。


Review 结论：用户认可设置与统计补充设计。本轮页面结构和关键流程 Review 完成，后续技术方案继续遵守已确认的功能范围与交互规则。
