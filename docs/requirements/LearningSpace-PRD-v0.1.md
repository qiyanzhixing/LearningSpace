## 1. 产品定位与目标

面向初中生家庭的学习工作台，当前重点服务初一孩子。将学校作业、自主学习、长期任务和锻炼整理为每日、每周可执行计划，并结合学校课程表、固定课外班和家庭可用时间安排工作量。

核心问题：

1. 孩子缺少计划，家长需要反复提醒下一步做什么。
2. 老师通过微信群发布作业，文字、图片与附件分散，整理成本高。
3. 固定课外班和临时作业挤占时间，长期任务缺少合理拆分。
4. 纸质试卷、练习册上的错题缺少统一记录。
5. 希望减少孩子使用电脑的时间，同时保留计划与实际执行记录。

产品目标：减少信息整理与提醒负担，帮助孩子参与规划并逐步独立管理任务；支持线上计划、纸上执行、集中回填。

## 2. 使用方式与设计原则

### 2.1 共用工作台

- 第一版不区分家长端、学生端，不设置家长和孩子独立账号，不做角色权限区分。
- 家长与孩子都可以录入、编辑、安排、完成任务和回填记录。
- 不记录谁修改了任务；任务来源仍保留，用于回查作业要求。
- “家庭共用”不表示公开访问。具体访问保护方式属于待确定的实现事项，不扩展成成员权限体系。

### 2.2 设备与交互

- 提供 Web 工作台，支持电脑和手机使用同一份数据。
- 电脑适合集中整理、查看周计划和打印；手机支持查看、录入、拍照上传、修改及回填。
- 每日学习任务采用“任务顺序＋预计用时”，不要求逐项绑定具体开始时刻。
- 学校课程、固定课外班按实际日期和起止时间呈现。
- 不引入多层项目、复杂看板、任务依赖图或繁重审批流程。
- 预计用时用于规划，不作为孩子必须按时完成的考核。

## 3. 第一版范围

| 模块 | 第一版包含 | 第一版不包含 |
|---|---|---|
| 共用工作台 | 共同管理任务与计划 | 家长/孩子独立账号、角色权限、修改人追踪 |
| 手工任务 | 一次性、重复性、科目/标签分类 | 复杂项目管理体系 |
| 微信与附件 | 粘贴文字、上传截图及 PDF/Word、提取要求、人工确认、保留原文文件 | 自动读取或抓取微信群 |
| 课程表 | 手工录入、修改 | 图片识别、文件导入课程表 |
| 课外班 | 每周固定重复、本次调课/取消、修改后续安排、准备及往返时间 | 与外部培训机构系统对接 |
| 学习计划 | 自动生成建议、预览调整确认、日/周查看、超量提示 | 静默改动已确认计划、自动延长可用时段 |
| 长期任务 | 按数量或步骤拆分、累计进度 | 多层任务依赖与复杂项目排期 |
| 执行记录 | 完成、部分完成、未完成重排、手工实际用时、批量回填、统计 | 在线开始/暂停计时器 |
| 打印 | 每日任务单、每周计划 | 错题练习单打印 |
| 错题 | 拍照、裁剪、分类、出处、备注、查看/搜索/编辑 | 复习安排、复习提醒、掌握状态追踪、自动解题、同类题生成 |

## 4. 核心使用流程

### 4.1 一次性设置

手工录入学校课程表 → 设置固定课外班及往返时间 → 设置每周各天可用时段 → 建立阅读、锻炼等重复任务。

### 4.2 日常规划与执行

录入手工任务或导入老师消息/附件 → 核对提取结果 → 生成建议计划 → 调整并确认 → 在线查看或打印 → 执行 → 填写完成情况和实际用时 → 必要时重新安排剩余任务。

### 4.3 自主学习

孩子可自行建立英语阅读、语文阅读等任务。持续活动使用重复任务，有明确终点的活动使用长期任务，再纳入统一每日计划。

### 4.4 错题记录

拍照或上传题目图片 → 裁剪 → 填写分类、出处与备注 → 保存 → 后续查找或编辑。第一版不从错题库自动生成学习任务。

## 5. 功能需求

### FR-01 手工录入与任务管理

支持创建、查看、编辑一次性与重复性任务；支持科目/标签分类。学习与锻炼任务均可录入，自主学习不需要来自老师通知。

任务需要表达的信息：

| 信息 | 业务含义 |
|---|---|
| 名称、具体内容 | 明确做什么，例如“数学练习册 P32–33” |
| 科目/标签 | 按语文、数学、英语等分类，允许表达阅读、锻炼等类型 |
| 任务来源 | 手工、微信消息；导入任务能回查原文和文件 |
| 预计用时 | 排计划依据，单位为分钟 |
| 截止/提交日期 | 最晚何时完成或提交，不等同于计划执行日期 |
| 重复规则 | 重复日期、周期等，用于生成每次任务 |
| 附件 | 对应图片、PDF、Word |
| 长期任务关联 | 本次任务属于哪个总目标或阶段 |
| 执行记录 | 完成情况、实际用时、完成数量/步骤等 |

字段必填与默认值的具体交互在设计阶段确定；自主阅读等没有外部截止要求的任务，不应被强制填写虚构截止日期。

重复任务每次独立记录完成与用时。调整、补做或跳过某一次，不改变后续重复规则；长期修改规则需明确作用范围。

### FR-02 微信消息与附件整理

支持手动粘贴消息、上传截图及 PDF/Word 文件，提取其中的作业要求，经人工核对后保存。

业务规则：

- 提取结果先作为候选任务，不直接写入已确认的学习计划。
- 支持修改、补充候选任务，并核对科目、具体要求、提交/截止日期与预计用时。
- 原始消息和文件与确认后的任务关联保留；一条消息可包含多项任务。
- 老师给出的截止信息与系统估计的用时应能区分，不把推测呈现成老师原文。
- 提取失败或信息缺失时，保留原始资料并允许手工补录，不能丢失内容或假装识别成功。
- 本入口面向作业要求整理，不承诺自动解题、批改或生成答案。

PDF/Word 的具体格式版本、扫描件覆盖程度、文件限制见第 10 节，需在实现前确认。

### FR-03 学校课程表

- 仅支持手工录入和修改，表达每周上课日期、科目和起止时间。
- 课程表可查看，并作为安排计划的参考和时间约束。
- 不根据课程表虚构老师尚未布置的作业。

### FR-04 固定课外班

支持设置名称、每周日期、开始/结束时间，以及准备、出发和往返占用时间。

| 修改方式 | 规则 |
|---|---|
| 调整本次 | 仅移动选中的一次课程，之后各周保持原安排 |
| 取消本次 | 本次停课/请假，不影响后续 |
| 修改之后的安排 | 从选定日期起更新后续固定安排 |

调课后检查与其他固定安排的时间冲突，并提示对已确认学习计划的影响。不得直接改动已完成任务。课外班本身与课外班作业分别管理，作业通过手工或消息入口录入。

### FR-05 可用时间设置

- 按每周各天设置通常可用于学习和锻炼的时段。
- 自动扣除与可用时段重叠的固定课程、课外班及准备/往返占用；同一占用不重复扣减。
- 支持某一天临时缩短、延长或调整可用时段。
- 计划需保留休息与缓冲，具体设置方式在界面设计阶段确定。
- 时间不足时提示超量，由使用者决定调整；系统不得自行延长到夜间或修改可用时段。

### FR-06 自动生成与确认计划

计划输入：任务提交/截止日期、预计用时、重复规则、长期任务剩余量、课程表、课外班及当天可用时间。

计划输出：每天建议安排的任务、长期任务今日份额、执行顺序、预计用时和必要的冲突提示。

业务规则：

1. 先生成建议，允许预览、修改后确认。
2. 截止日期是重要约束；无截止日期的自主任务仍可参与安排。
3. 任务按顺序与预计用时呈现，固定活动按时刻呈现。
4. 临时新增作业进入待安排范围，展示截止信息，不自动打乱已确认计划。
5. 已确认计划需要调整时，展示拟调整内容，由使用者确认后生效。
6. 截止前排不下时明确提示冲突，不静默丢弃任务或擅自修改截止日期。
7. 已完成记录保持不变；已打印计划发生变化时提示变更，便于重新打印或手动补充。

自动计划的优先级权重、估时方法等属于实现设计；不能以实现细节改变上述人工确认与时间边界。

### FR-07 长期任务拆分

| 类型 | 示例 | 拆分与进度 |
|---|---|---|
| 按数量 | 截止日前阅读 100 页 | 将数量分配到可用日期，累计实际完成量 |
| 按步骤 | 作文提纲、初稿、修改 | 设置步骤及各自预计用时，按步骤累计进度 |

- 系统建议每日份额，可调整后确认。
- 每日份额作为可执行任务进入计划；母任务保留总体范围、截止日期与进度。
- 母任务与每日份额不能重复计入当天工作量及实际用时。
- 修改后续安排不抹除已经完成的数量、步骤与用时。
- “每周三次、每次 15 分钟英语阅读”属于重复任务，不要求设置总量或终点。

### FR-08 预计用时

- 一次性任务可由系统给出估计，人工核对时可修改；无法估计时提示填写。
- 重复任务设置默认用时，允许单次调整。
- 长期任务拆成每日内容后分别估时。
- 完成后保留与该次执行对应的预计用时，作为计划与实际比较依据。
- 不用实际用时反向覆盖原预计用时。

### FR-09 执行、部分完成与重新安排

支持完成记录、修正记录，以及保留当天已完成部分与实际用时。

未完成处理规则：

1. 剩余部分进入“待重新安排”，不直接全部滚入明天。
2. 系统参考截止日期和后续可用时间提出建议，人工确认后安排。
3. 已逾期或无法在截止前完成时明确提示，不改写截止日期。
4. 重复任务本次未完成，可以选择补做或跳过，不影响后续重复安排。
5. 补做/重排关联原任务剩余部分，不应生成重复工作量或重复完成记录。

“未安排、已安排、部分完成、已完成”等可作为业务状态，但不要求在界面上呈现复杂状态流程。普通作业部分完成的具体输入形式在设计阶段确定；数量型、步骤型任务应能记录完成量或步骤。

### FR-10 实际用时与统计

第一版采用手动填写及批量回填，不提供在线开始/暂停计时器。

- 完成时或晚间集中填写实际用时，允许后续修改。
- 按任务投入时间记录，不包含中途吃饭、休息等时间。
- 未填写时显示“未记录”，不记为 0，也不以预计用时代替。
- 跨日任务保留每天实际投入，重排不得覆盖之前的用时。
- 支持按日、周、科目汇总实际用时；学习与锻炼分别汇总。
- 支持查看预计与实际的差异，方便改进后续估时。
- 有缺失记录时，统计应说明数据不完整；预计/实际差异应基于可比较的记录，避免把缺失值当作节省时间。

上述实际用时统计针对执行任务；固定课程出席时长是否另外统计，第一版不作已确认需求。

### FR-11 打印与批量回填

支持打印每日任务单和每周计划，适合 A4 黑白打印。

| 打印内容 | 应包含的信息 |
|---|---|
| 每日任务单 | 日期、固定安排、任务顺序、具体内容、预计用时、完成勾选框、实际用时空栏 |
| 每周计划 | 每日任务及固定安排、必要的预计用时与记录空间 |

- 纸上完成后可批量回填完成情况、完成量/步骤及实际用时。
- 尚未回填只表示系统尚无执行记录，不应自动判断孩子没有学习。
- 打印内容需能够关联到对应日期和任务，修改任务后仍可准确回填。
- 第一版不打印错题练习单，不要求识别纸上勾选或手写实际用时。

### FR-12 锻炼任务

- 每日计划包含锻炼内容，可建立一次性或重复任务。
- 设置内容与预计用时，支持完成记录及实际用时回填。
- 与学习任务共同显示在今日顺序中，但统计单独汇总。
- 有明确上课时刻的体育课外班通过固定课程管理；不自动再生成一项同内容锻炼任务。

### FR-13 错题记录

第一版只做记录与检索，不做复习管理。

包含：拍照/上传、裁剪、分类、记录出处、备注、查看、搜索和编辑。原题图片应保留；裁剪后的题目用于清晰展示。

建议记录内容为科目/标签、试卷或练习册名称、页码/题号、图片及备注。具体表单必填项待设计确认。

明确排除：安排重做、自动加入学习计划、复习日期与提醒、复习结果历史、掌握状态、自动解题、生成同类题。若使用者自行创建一项普通“复习”任务，属于通用任务功能，不代表第一版建立错题复习系统。

## 6. 页面与信息结构建议

本节为支撑已确认功能的信息结构建议，页面名称与布局待界面 Review，不作为新的功能扩展。

| 页面 | 重点内容 |
|---|---|
| 今天 | 今日固定安排、执行顺序、预计用时、完成和实际用时、打印入口 |
| 计划 | 周计划、建议计划预览与确认、长期任务及重新安排 |
| 任务 | 手工添加、消息/附件整理、待确认与待安排任务、分类查询 |
| 错题 | 图片记录、分类查询、出处与备注 |
| 设置 | 手工课程表、固定课外班、每周可用时间；统计入口位置待设计 |

首页以“今天接下来做什么、还有多少、有哪些时间约束”为重点。所有使用者进入相同工作台，不按家长或学生分流。统计、录入和配置不应挤占执行清单。

## 7. 跨模块一致性与质量要求

- 电脑和手机查看同一任务时，内容、计划和完成记录应保持一致。
- 保存失败、提取失败、文件不支持等情况需明确提示，并保留可恢复的输入。
- 修改任务、重复规则和长期拆分时明确影响范围，避免覆盖历史事实。
- 计划、打印和回填应使用同一套任务信息，避免独立维护多份清单。
- 手机窄屏能够完成关键操作；表格或长附件不应使整页无法阅读。
- 文件和错题属于家庭资料，不应因共用模式默认公开。部署、访问保护、备份与恢复方案在实现前确定。
- 统计数据用于理解工作量与估时，不以排名或惩罚机制驱动孩子使用。

## 8. 第一版验收场景

| 编号 | 场景 | 可验收结果 |
|---|---|---|
| AC-01 | 手工创建一次数学作业与每周三次英语阅读 | 正确分类；阅读每次独立完成；单次调整不影响后续 |
| AC-02 | 粘贴老师消息并上传配套截图、PDF、Word | 出现候选任务；可核对修改后保存；能回查原文文件；不直接修改已确认计划 |
| AC-03 | 识别结果缺少日期或提取失败 | 可查看资料并手工补录，不虚构为确定信息 |
| AC-04 | 手工创建与修改课程表 | 周计划中可查看；排程考虑相应时间占用，无图片导入前置要求 |
| AC-05 | 将本周英语课调至另一天 | 仅本次变化，后续周不变；冲突和计划影响可见 |
| AC-06 | 设置某天可用两小时，并有重叠课外班及往返占用 | 正确扣除重叠占用；建议任务不把被占用时间重复利用 |
| AC-07 | 有紧急作业、阅读和周五截止作文 | 参考截止日期生成建议；可调整确认；排不下时明确提示 |
| AC-08 | 确认并打印计划后新增老师作业 | 原计划顺序不被静默修改；新增任务可参与新的建议并确认 |
| AC-09 | 建立 100 页阅读与三步骤作文 | 可拆为每日份额；完成后累计进度，母子任务不重复计时 |
| AC-10 | 任务当天只完成部分，投入 20 分钟 | 保留完成部分及 20 分钟；剩余进入待重排，确认后再安排 |
| AC-11 | 重复任务本次未完成 | 能选择补做或跳过；后续重复安排保持独立 |
| AC-12 | 打印日任务单/周计划，之后集中回填 | 打印可读且有记录空间；批量保存正确关联任务与日期 |
| AC-13 | 部分任务填了实际用时，部分未填 | 未填显示未记录；统计不当作 0 或预计值；学习与锻炼分开 |
| AC-14 | 拍照记录练习册错题 | 可裁剪、分类、记录出处和备注，后续能搜索及编辑；不自动生成复习计划 |
| AC-15 | 在手机录入或回填后用电脑查看 | 可访问同一份已保存数据，无角色端切换要求 |

## 9. 范围变更摘要

以下为对早期讨论与研究建议的正式修订：

1. 取消家长端、学生端区分；第一版无独立成员账号、权限和修改人追踪。
2. 课程表从“支持导入”收敛为“仅手工录入、修改”。
3. 错题从“记录并系统复习”收敛为“仅记录、检索和编辑”。
4. 打印范围为每日任务单、每周计划，不含错题练习单。
5. 实际用时采用手工填写和批量回填，不做在线计时器。
6. 自动计划以提交/截止日期与可用时间为依据，调整必须确认，不静默改动既有计划。
